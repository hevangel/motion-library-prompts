# site/ — runnable copy of the original Motion Library

Snapshot of <https://kittenjam-motion-library.vercel.app/>
(fetched 2026-10-28 by `../tools/extract.py`), plus a language toggle
added for this clone (below). This is where every prompt's animated
example actually runs.

| File | Role |
|---|---|
| `index.html` | Page shell, filters, submission dialog — verbatim except the injected language-toggle hooks (marked `ml-i18n`) |
| `data.js` | Taxonomies (`COMPS` / `WHENS` / `USES`) + `ITEMS` — all 327 prompts and metadata |
| `fx.js` | `FX[id]` — the animated example implementation for each effect, plus shared helpers |
| `fx.css` | Per-effect `.fx<id>` styles and shared category CSS |
| `app.js` | Card rendering, filtering, and the 「複製 AI 提示詞」 copy logic |
| `tracking.js` | Original author's Vercel Analytics opt-out helper (inert locally) |
| `og.png` | The site's social-preview image |
| `data_en.js` | **Added:** English translations of all 327 effects (`ITEMS_EN`), generated by `../tools/build_en.py` from `../translations/en.json` |
| `i18n.js` | **Added:** the 中文 / EN language toggle (see below) |

## Language toggle （中文 / EN)

A segmented **中文 / EN** button sits in the header toolbar. Chinese
(the original) is the default. Switching to EN translates:

- all page UI (header, search, filters, sort, mini bar, empty state,
  submission dialog, footer),
- the component / timing / use labels in chips, selects and section
  headers,
- every card's name order (English first), description, tags and its
  stage tag,
- the animated previews' sample text (e.g. 雷鳴 → “Thunder”),
- the copied prompt — the copy button becomes “Copy AI Prompt” and
  produces `"<en> (<zh>)" motion effect: <English prompt>` plus an
  English palette line,
- search keeps matching both languages in either mode.

The choice persists in `localStorage` (`ml-lang`) and can be forced
with `?lang=en` / `?lang=zh`. `i18n.js` runs after `app.js`, swaps the
taxonomy labels in place, repaints card meta, swaps each item's
preview text/tag so `build()`/`teardown()` pick them up, and wraps
`render()` to fix the few strings `app.js` hardcodes in Chinese.
Re-running `../tools/extract.py` restores `index.html` to verbatim —
re-run `../tools/build_en.py` afterwards to re-inject the hooks
(`data_en.js` and `i18n.js` themselves are not touched by the extractor).

Run it:

```bash
cd site
python3 -m http.server 8000
# open http://localhost:8000
```

Notes:

- GSAP 3.13 and Google Fonts load from CDNs — the demo needs internet.
- The `/_vercel/insights/script.js` tag 404s outside Vercel; harmless.
- The 「我要投稿」 submission dialog still posts to the **original author's**
  FormSubmit endpoint (see the end of `app.js`). It is kept for fidelity —
  remove that section before publishing this copy anywhere of your own.
